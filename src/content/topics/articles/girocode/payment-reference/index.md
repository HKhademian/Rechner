# Payment reference and purpose code

A remittance reference helps a recipient identify a payment. Structured references use a defined format; unstructured references contain free text. A purpose code describes the kind of payment.

## Potential benefit

An accurate reference can help the recipient match a transfer to an invoice or account.

## Conditions and limitations

Use the reference requested by the recipient; a purpose code is separate and optional. Bank support and format limits apply.

## In the calculators

The generator places the selected reference format and optional purpose code into the payment code.
