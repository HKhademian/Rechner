# Employee Work-Expense Lump Sum (Arbeitnehmer-Pauschbetrag)

Grants an automatic standard annual work-expense deduction (€1,230) against employment income without requiring receipts.

## Benefit

Automatically reduces taxable employment income by €1,230 per employed person per year.

## Limitation

Already built into standard payroll tables, so it only generates an extra refund if actual itemized expenses exceed €1,230.
