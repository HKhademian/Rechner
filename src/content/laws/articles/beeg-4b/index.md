# Partnership Bonus (Partnerschaftsbonus)

Provides 2 to 4 additional ElterngeldPlus months for each parent if both simultaneously work 24–32 hours/week in consecutive months.

## Benefit

Unlocks up to 4 extra ElterngeldPlus months per parent beyond the standard 14-month family budget.

## Limitation

If either parent breaks the 24–32h/week corridor in any consecutive bonus month, the bonus months can be reclaimed.
