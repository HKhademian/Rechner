# Ideation and Investigation Documentation

Ideas, plans, comparisons, and investigations are the most valuable assets during early project development. They must be permanently documented and tracked within the project.

- **Separation of State**: Do not mix brainstorming or ideation documents with the "current state" documentation (e.g., architecture docs). 
- **Storage Location**: Store all brainstorming, mechanics explorations, and future blueprints in the `.agents/ideation/` directory.
- **Commit Appropriately**: Even if these ideas are not yet implemented in code, they MUST be committed to the Git repository atomically so future agents have access to the project's intellectual history and intended direction.
