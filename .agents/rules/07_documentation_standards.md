# Documentation Standards
The project must be heavily documented for its purpose:
1. **Architecture & Management**: Important documentation for architectural decisions, product, management, etc., must be stored in the `.agents/` directory.
2. **Inline Code Documentation**: There must be inline documentation with simple explanations of what the code is doing.
3. **No Over/Under Explaining**: Do not over-explain or under-explain. Do not write comments that just repeat what the code says (e.g., avoid `/* adds a and b */ a+b`).
