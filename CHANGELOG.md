# Changelog

Notable user-facing changes to Rechner are grouped by release. Unreleased changes appear first.

## [Unreleased]

### Added

- Added a proprietary license allowing free personal and small-business internal use while requiring a written grant for client-facing consulting, redistribution, and other restricted uses.
- Added a project-wide use, accuracy, warranty, and liability notice.
- Added a visible footer notice linking to the terms for hosted calculator use, including automated access.
- Published the Rechner calculator catalog and workspaces on GitHub Pages.
- Added selectable page-only, tab-only and on-device storage modes for calculator inputs.
- Added visible source revision provenance to calculator pages and saved exports.
- Added search, category filters and direct links for the calculator catalog.

### Changed

- Clarified calculator descriptions, source links and catalog navigation.
- Source revision links now identify the source commit, personal-use license and use terms.
